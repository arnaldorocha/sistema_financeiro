# Sistema de Gerenciamento Financeiro

Este é um sistema de gerenciamento financeiro desenvolvido com **Flask** e **SQLite**, projetado para ajudar usuários a monitorar e organizar suas finanças pessoais. 

## Funcionalidades

- Cadastro e login de usuários com autenticação segura.
- Dashboard financeiro interativo com visualização de metas e transações.
- Gerenciamento de transações financeiras (rendas e despesas).
- Edição de metas financeiras mensais.
- Geração de relatórios CSV.
- Notificações automáticas de rendas e despesas.
- Calendário de avisos de contas a pagar e rendas a receber (em desenvolvimento).
- Relatórios detalhados com gráficos (em planejamento).
